# Города - Игра в города

Интерактивная игра "Города" с использованием React и TypeScript. В этой игре пользователь соревнуется с компьютером, называя города по очереди. Каждый следующий город должен начинаться на последнюю букву предыдущего города.

## Особенности

- 🎮 Интерактивный игровой процесс
- 🤖 Искусственный интеллект для ходов компьютера
- 📱 Адаптивный дизайн
- 🎯 Разные уровни сложности
- 📊 Отслеживание статистики игры
- 🎨 Современный пользовательский интерфейс

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router


## Правила игры

1. Каждый следующий город должен начинаться на последнюю букву предыдущего города
2. Город не может быть использован повторно
3. Если последняя буква - "ь" или "ъ", используется предпоследняя буква
4. После 15 ходов игра переходит на повышенный уровень сложности
